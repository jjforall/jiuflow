
# 動画時間表示の修正計画

## 現状分析

### コードは実装済み
- `VideoCard.tsx`（行124-129）: サムネイル右下に時間バッジを表示するロジック
- `handleFetchAllDurations`（行341-415）: 動画時間を一括取得する機能
- `fetchDurationFromVideo`（行418-444）: Cloudflare StreamからMP4で時間を取得

### 問題
データベースを確認したところ、**`video_metadata`に`duration`フィールドが含まれていない**ため表示されていません。

```text
現在のデータ例:
video_metadata: { ja: { video_url: "...", created_at: "..." } }
               ↑ durationがない！

必要なデータ:
video_metadata: { ja: {...}, duration: 180 }
               ↑ これが必要
```

## 解決策

### 必要なアクション（手動操作）
1. 管理画面の技術管理ページを開く
2. ページ最下部の「管理ツール」セクションを展開
3. **「動画時間一括取得」ボタン**をクリック
4. 処理完了後、動画一覧のサムネイルに時間が表示される

### 表示される場所
```text
┌────────────────────┬─────────────────────┐
│ [サムネイル]       │ タイトル            │
│ ┌──────────────┐   │                     │
│ │              │   │ 日本語名            │
│ │    ▶        │   │                     │
│ │         ⏱3:45│ ← ここに時間表示       │
│ └──────────────┘   │                     │
└────────────────────┴─────────────────────┘
```

## 確認が必要な点

もし「動画時間一括取得」ボタンが見当たらない、またはエラーになる場合は、管理ツールセクションがUIに正しく表示されているか確認が必要です。

管理ツールボタンの表示部分を確認して、必要であれば修正します。
